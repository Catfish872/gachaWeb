## 来源与制作
全部使用内建 image_gen 原创生成，2026-11-02，供本项目使用。未使用用户私图或外部第三方照片，无外部素材署名义务的新增来源。此说明为来源记录，不保证生成内容独占性。

统一提示方向：高品质幻想动漫游戏插画，烬金灯火，深酒红/象牙/墨黑/氧化铜/金白细火丝，清晰剪影，无文字星级品质框。瑟琳为成年女性人类守灯人；角色与 CG 使用已生成原创立绘保持身份一致。六背景独立生成，非概念图集放大。

运行资源规格：立绘 1024×1536；6 场景、主视觉及2 CG 为1672×941；表情640×640，独立脸部头像512×512；敌人及容器512×512；物品256×256；套装技能祝福384×384。

源图集在工作区 generated_images，仅实际独立切片进入 Godot。切片脚本保留源坐标：角色表情2×2、敌人3×3、容器3×2、物品5×5、遗物技能祝福4×4。生成模型并未保证理想等格，已按实际像素边界调整，不能盲用等格裁切。最终每片至少16px安全留白，RGBA alpha原样保留，未硬阈值抠图。怪物/容器画布固定、底部锚点(0.5,1.0)；UI应使用统一容器尺寸和KEEP_ASPECT，不随回合拉伸。

图像导入配置：lossless compress/mode=0，fix_alpha_border=true，mipmaps关闭，非premultiplied alpha。Godot正式资源导入由统一验收/构建执行，不另开全量游戏测试。
