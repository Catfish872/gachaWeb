# 雷角色正式美术整合复核

基于批准的 anime-review-v2 角色设计，替换三名角色、莱莎雷铠、三种雷铠动作和三张幕间插画，并加入三张抽卡双层背景，共13张独立素材。`godot/assets/content_v290/character_art_manifest.json` 记录正式运行资源的尺寸、透明范围和 SHA256。`tools/verify_thunder_art_v290.py` 核验清单与角色、技能、剧情、卡池的引用关系。

莱莎、维珂、伊芙头像分别使用原图区域 `(440,70,300,300)`、`(225,70,300,300)`、`(425,210,300,300)`。抽卡界面保留前景全身，背景加入对应角色的大半身与独立环境。幕间插画在对话框上方等比完整显示，递面包、地图和递粥的互动道具均完整可见。

首次整合已通过云桌面的 Godot OpenGL Compatibility / llvmpipe 实际渲染，检查1440×810与960×540画面。检查使用 Dummy 音频驱动，验证画面而非声音。后续执行环境重建，素材从持久文件逐一恢复并校验 SHA256，生产代码按已验收改动复刻。此前截图随旧工作区丢失，恢复版本的专项日志位于 `godot/validation/v290-revised-art/`。两个专项测试支持重新生成相同视口的截图。

针对性检查包括头像141项、抽卡背景73项、角色与CG42项、雷角色视觉134项、抽取308项、战斗80项，以及13张美术清单、42个雷队图标、第五章内容校验。原头像测试已按发布版本现有的完整原图胸像与独立头像行为更新，角色加载逻辑保持原有行为。

目录数据仅修改三项卡池背景路径；角色数值、技能效果、抽卡概率和存档模型保持原样。本记录属于专项回归与此前实际画面检查，恢复后的检查结果以同目录最终日志为准，完整发布验收由发布流程汇总。
