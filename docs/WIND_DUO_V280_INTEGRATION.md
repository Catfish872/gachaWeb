# 双风战斗集成规则

本文件记录正式接入规则。V6 原型数值与路线结论并非本次正式版本测试结果；正式回归结果应以统一验证记录为准。

## 技能与伤害

- 缇娅与露弥的六项主动技能使用两次原生伤害。`onHitPerActionTarget` 让每份命中施加状态、状态命中回能祝福对同一目标每行动只判断一次。
- 缇娅每次主动行动结束，对该行动承受过自身有效原生伤害且仍存活、仍破甲的目标各追加一次 60% 原始攻击力风属性贯穿追击，六命改为 66%。本次行动全部被盾吸收的目标不记为有效命中。
- 贯穿沿正常属性伤害链计算，但 `defPierce=1`、无法暴击。采用永久计算攻击值，不吃临时攻强；吃元素克制、佩戴者条件追击加成及外部伤害加深。普攻/战技/终结技伤害区和普通状态祝福伤害区不乘入。
- 贯穿不会派生命中祝福、能量命中、暴击触发或再追击；保留既有吸血与击杀回能规则。
- 共享金祝福每份在同一行动同一破甲目标受到至少两次有效原生伤害后追加一次 36% 攻击力贯穿，和角色固有追击分别标记。队内任意有两次原生伤害的角色可以触发。

## 破甲、露弥与百桥弦约

- 破甲按最强数值和最长剩余持续时间刷新。基础35%，露弥六命主动施加45%。多次施加不相加百分比或持续时间。
- 露弥存活时，友方对破甲目标的外部伤害加深15%；破甲敌人对友方造成伤害的系数乘80%。可识别来源的持续伤害同样处理。守护蓝祝福每份再减8个百分点，共享既有90%常规减伤下限。
- 百桥四件额外提供12%永久攻击；泛用佩戴者事件为佩戴者主动施加破甲后，全体友方获得2回合风誓。角色固有贯穿追击基础倍率提高40%。不绑定佩戴者或受益者ID，不作用于祝福产生的贯穿。
- 风誓40%与缇娅白祝福每份1/15、金祝福每份1/6在固有追击倍率区相加，然后再乘佩戴者条件增伤、外部加深等区。
- 开场金祝福固定施加35%破甲3回合，由祝福本身产生；不受露弥六命主动施加规则影响，不触发百桥。白色持续祝福仍可延长该破甲。
- 通用淬毒锋刃每份概率20%。中毒永久层数、独立攻击快照及伤害公式不改。艾拉机制和祝福池不改。

## 遗物推荐参考

巡岚双刃与百桥弦约的两件效果均为12%攻击，四件各额外提供12%攻击。因此同词条四件与两套攻击两件的永久攻击面板相同，再分别计入原有20%佩戴者追击增伤和40%团队固有贯穿倍率。两套原有触发条件、持续时间和倍率保持。角色基础属性、主动技能与祝福数值保持原值。露弥对破甲目标的团队伤害加深由20%调整为15%，减伤仍为20%；同条件输出乘区由1.20变为1.15，用于约束新双四件的全队增幅。无专属的过渡队在破甲覆盖期间，该项调整对应约4.17%的输出减少，防护与破甲能力保持。

保留逐槽最高星级优先。双风采用六次合法行动的输出参考，缇娅加入非暴击贯穿；露弥额外计当前已装备队友平均技能伤害和固有贯穿的增量。假设破甲及可触发百桥持续覆盖，队友技能均权平均；没有模拟起手覆盖、行动顺序、护盾或生存。该评分用于该声明场景，不代表所有实战。

含团队固定增量、非暴击贯穿的目标不使用攻击暴击齐次缩放捷径，改用保守完整参考上界；效果缓存包含两个新套装类型。星级筛选、库存范围、金币与强化规则不变。

## 新敌行动与风场

- 仅数据声明 `actionCycle` 的敌人启用周期，实际执行预期技能后推进游标，控制跳过不推进。阶段切换前刚预警则保留下一次群攻承诺，否则从新阶段预警开始。
- `boss_ally` 只指向同阵营存活首领。`refreshDuration=true` 同来源状态覆盖持续时间，同来源护盾取现有剩余盾与新盾的较大值；不累加。
- 风场独立可选中，击破后不再刷新增益，既有增益按剩余回合自然到期。阶段切换不重建单位。

原火队瑟琳回归 **92 通过、0 失败**；原遗物优化器实战预测回归 **37 检查、0 失败**。日志分别为 `godot/validation/v280-focused/selin_v270.log` 与 `relic_optimizer_battle_v250.log`。
