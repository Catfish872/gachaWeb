# 长风栈道与第四章敌人接入合同

本次内容以2.7.8为基线。搜打撤保留三幕，新局通过既有独立环境随机数从灰烬王城、苍翠秘林、星辉圣域、烬灯驿路、长风栈道五种主题无放回抽取三种。长风栈道标识为windpass，三个区域依次为谷口外驿、悬枝风廊、云巢风庭，每幕仍有十八个普通房间和一个首领房间。钥匙价格为500金币，钥匙串、开门、穿戴保护、回收、寄存与撤离入口沿用当前规则。

## 地图、容器与战利品

八张背景分别绑定到三个区域的候选表。谷口外驿采用风谷外驿、散包山径、避风种圃；悬枝风廊采用悬索旧桥、测风塔、积水风廊；云巢风庭采用云巢风庭与风轮高台。每个房间在生成地图时确定背景，首领使用云巢风庭。三个区域分别读取windpass_road、windpass_gallery、windpass_core音乐。

巡路信箱、草药背篓、桥匠工具柜、风铃供台、封存图箱、风庭宝匣均为独立容器。草药背篓连接补给与疗愈用品类别，桥匠工具柜连接工具、零件、整备与装备。医院、工坊和宝库的专用分类仍先于容器外观生效。

二十四件主题战利品覆盖六个品质，每品质四件。每件从绑定的基础物品完整复制尺寸、价格、品质、类别、用途、历史价值和掉落权重，再替换名称、说明与外观。抽取首先选择基础物品，其后按当前主题取得外观变体，因此主题件保持基础池的票数和概率。风庭图室钥匙同样作为key_ruins的主题变体进入掉落，而购买与开门明确使用key_windpass。

三个主题事件为替巡路者整理行囊、协助固定导风帆、查看封存运单。每个事件四项选项随机保存三项，事件类型避开最近两次，已有房间保存菜单并复用。所有奖励使用当前即时整备、金币或生命支出、祝福选择、容器搜索和钥匙接口。选择前显示便携物资的类别与份数，同时显示实际金币、生命代价和即时恢复数值。便携药品与钥匙先进入可搜索容器，搜索领取后才进入背包或钥匙串。旧四主题继续使用原九类事件。

## 敌人准入与模式预算

普通敌人为wind_falcon、leaf_spirit、moss_climber、bridge_warden、songwing_attendant；精英为brokenbridge_hunter与windwheel_sentinel；首领为boss_highland_roc。windfield_updraft与windfield_crosswind是首领编队中的两处独立目标。主线十二关使用明确编队。搜打撤长风栈道读取自己的普通、精英、首领表，其余四主题保留原表与编队。深渊将八种主要敌人分别接入普通、精英与首领池，使用独立abyssBaseStats和现有层数成长。深渊首领编队为高岭风鹫本体，两个风场用于主线和搜打撤。

深渊基础属性按生命、攻击、防御、速度排列：切风隼420/80/25/115，以雷鹰为基准；卷叶灵350/50/25/85，以哥布林为基准；苔甲攀兽500/55/60/60，以冰霜雪狼为基准；失序桥卫380/45/35/75，以哥布林为基准；鸣翼侍鸟380/45/25/95，以鸣炉侍为基准。断桥猎隼1100/90/85/105、旋臂护桥机1200/80/100/70均对照黑暗骑士。高岭风鹫5500/140/55/100对照风暴女巫。切风隼、苔甲攀兽、鸣翼侍鸟从第四层加入普通池，其余普通敌人从第一层准入。

高岭风鹫主线本体22000/290/145/110，两风场各2500/1/75/90。搜打撤对完整三目标编队归一：参考首领为风暴女巫，基础生命5500、攻击140、防御55、速度105。危险等级四计入黑暗骑士1200生命，危险等级五再计入雷鹰420生命。高阶护卫攻击转换系数为0%，其生命完整保留；灯火主题的既有25%攻击转换保持原值。生命与攻击归一分别使用完整编队总生命27000和总攻击292，再叠加既有幕数、危险等级、首领与末幕倍率。末幕1.15仅作用于首领本体，两个附属目标保持通常倍率。风场额外单体攻击通过已签发enemyAttackOverrides独立赋值：危险0至3各15原始攻击，危险4为90与15，危险5为90与80，再乘同幕同档通常攻击成长。该份额保留在两风场，首领的群攻倍率保持上述预算。旧主题沿用原攻击计算。

## 预警、阶段与风场

首领第一阶段按照振翼聚风、风庭长啸循环，伤害倍率依次为1.3单体、1.0全体。第二阶段按照高空盘旋、高岭风暴循环，依次为1.5单体、1.4全体。群攻后的预警动作同时执行单体攻击，兼顾持续进攻和可见预告。每次全体伤害前都有一个明确写出“下次行动全体”的预警技能，全体伤害后继续单体进攻。实际技能执行才推进循环，控制跳过保留待执行位置。切换阶段时，刚执行预警的单位继续兑现预警；其他位置从新阶段预警开始。生命、状态与单位标识沿用同一战斗实体。

失序桥卫、断桥猎隼与旋臂护桥机同样使用三步循环，依次为轻击蓄势、重击、普通攻击。旋臂护桥机蓄势时获得最大生命4%的自盾，扫击为0.75倍全体，其余两种重击为单体。六行动预算以黑暗骑士满生命时的实际冷却与护盾策略对照，同时记录防御、耐久与峰值。

上升风场给存活首领8%攻击增益，横切风场给予施法者最大生命8%的护盾。每个风场在辅助效果后各执行一次1.2倍单体攻击，采用自身的独立攻击份额。两者持续两回合，按来源刷新持续时间，护盾刷新取现有值与新值的较大者。每次刷新保持单份效果，风场消失后现存效果在最多两个回合末到期。风场具有独立生命与目标标识，玩家可以分别选择。深渊本体以独立基础预算与相同预警循环作战。

## 保存边界与验收入口

主题顺序只在新局生成；旧局的环境顺序、地图、正在进行的遭遇、签发种子和随机数状态保留。重复prepare_battle读取既有配置。深渊背景通过敌人的显式适配场景与已签发种子确定，背景读取保持随机数状态。旧灯火场景通过原敌人标识识别，新的深渊基础属性字段与主题识别分别处理。

定向入口为test_wind_world_v280.gd与test_wind_enemies_v280.gd。前者覆盖新旧环境、地图配额、二十四件物品实际生成至撤离的完整链路、钥匙购买开门、事件保存与深渊入口；后者覆盖实际循环动作、预警与控制、阶段变化、风场选中和有界刷新，并输出三人中性目标、防御0/100/500与有盾条件下的六行动完整编队结果。预算采样固定32个种子，逐动作使用当前伤害公式计算暴击期望，再实际执行动作维持技能冷却与增益。输出含总伤害、单人峰值、全队行动峰值、护盾与生命损失。新首领逐项对照风暴女巫及相应高危护卫，动态验收由版本集中窗口记录。
