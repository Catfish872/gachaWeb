# 雷队遗物参考与独立审计

雷队遗物推荐继续使用实际三人编队与队友当前装备。角色处于编队外时，按既有三个队伍位置构造参考队伍。逐槽最高星级筛选、可用库存、装备归属、强化等级、金币、精确搜索证明与快速推荐的质量保障保持原规则。新角色没有套装名称加分；所有套装由其属性与战斗效果进入同一个目标函数。

莱莎按照实际充能、冷却和自动施放优先级构造普通形态与雷铠形态的循环。变身行动占据持续时间中的第一回合，零命之后依次使用普攻、战技、终结技；六命多一回合终结技。普通形态逐次计算行动回能后的攻击力，逐目标保留暴击回能与能量攻击力的相关性。雷铠能量保持100，结束归零。普通伤害段与无法暴击的贯穿伤害段分别计算，只有能够暴击的伤害段参与暴击回能概率。

维珂追击按实际每目标每回合最多两次合并。单体攻击选择首个目标，群体攻击分别覆盖每个目标；同一行动的两个原生伤害段提供一次追击机会。开局参考逐回合求各角色命中分布，再合并上限。确定充能的长期参考保留每个队友的暂态与循环相位，在共同周期上计算，因此能够识别三个角色同轮命中时被两次上限截断的收益。含随机暴击回能的长期参考采用独立稳定相位假设，此项是评分场景假设，逐场实际战斗由战斗引擎执行。

参考队伍会识别队友技能施加的导电、破甲、燃烧与感电。导电减防、露弥命座破甲与团队加深、缇娅固有贯穿、雷轨套装雷铠增伤、百桥增益均沿实际战斗公式计算。瑟琳提供六回合燃烧参考下的引爆、套装增益、命座追加伤害与按循环覆盖率加权的誓约；燃烧采用队内实际可施加燃烧的来源。护盾、导电、破甲、套装状态与六回合燃烧采用持续覆盖参考。击杀、断盾、控制、状态起手与双方行动先后属于实际战斗条件。

伊芙的目标函数采用生命值单位，分别累加主动治疗、护盾供给、盾下被动治疗与再生。队伍伤害独立列出。治疗参考持续存在足够缺失生命，护盾参考持续消耗并获得补充，所以该值表示潜在供给；满血或护盾未消耗时的实际收益由战斗决定。

专项测试入口为 `godot/tests/test_thunder_optimizer_v290.gd`。本轮独立检查包含72项，覆盖零命与六命变身循环、真实战斗单体循环对照、暴击回能顺序、不可暴击伤害段、当前导电减防、开局追击上限与真实战斗对照、同步周期相关性、混编状态识别、火队燃烧、队伍上界、精确搜索穷举对照、快速推荐、缓存以及存档和游戏随机数保护。结果记录在 `godot/validation/v290-thunder/optimizer-independent.log` 与同名JSON中；该记录与其源文件哈希对应，后续数值更新由最终验收重新确认。

独立平衡脚本为 `godot/tools/audit_thunder_balance_v290.gd`。它保存相同角色位置的合法五星25级生成词条、各队自身套装、零命和六命、真实目录中的等数量与等稀有度祝福组合。深渊采用原生难度3成长，搜打撤采用原生第三幕第四节点首领生成器。每组同时保存原生自动战斗的生存结果和独立输出窗口，后者保留模式缩放防御与目标数，将敌人改为中性、无限生命并省略敌方行动，以区分输出与生存。

该脚本共48组，输出包含6、12、24、48、96回合累计量、按角色与技能统计、普通和贯穿伤害段、祝福组合、实际生成的敌人属性、装备夹具与前后源文件哈希。输出窗口属于固定构筑诊断；祝福为合法构造组合，获取概率与自然远征路线另行验证。六命低防、高防与不同祝福组合的最终强度，以战斗组完成调校后的最新报告为准，历史快照保留当时实际观察结果。

最终战斗候选补充：莱莎五命从通用终结技伤害改为常态额外30%充能，评分继续调用实际 action_energy_gain，因此同样使用此门槛。雷铠战技及终结技的三个目标按实际 chainDecay 与 chainFloor 逐个计算，不把主目标倍率复制到所有目标。72项优化器测试在该候选上重跑通过，最新记录为 optimizer-final.log。原 optimizer-independent.json 保留的是独立审查时的源码快照，不用于宣称后续代码哈希未变化。
