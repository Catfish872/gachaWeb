## 开始游玩

1. 解压完整文件夹，用 **Godot 4.6.3** 导入 `project.godot`。
2. 按 F5，或在项目管理器选中工程后点击「运行」。
3. 新档可先十连并编队；主线逐关开放，用金币训练和遗物完善角色，再尝试深渊远征。
4. 远征入口展示本次队伍、层数、路线、祝福、资源和永久传承。途中有选择时，自动战斗会暂停。

这是 **Godot 源工程**，不包含 APK 或 Windows 可执行文件。Android 导出仍需对应模板、JDK、SDK 和签名；未声称完成手机真机触摸、后台恢复或性能验收。

## 本轮玩法

- **无限深渊**：每 10 层为首领里程碑，20 层之后继续探索，不设通关终点。失败或主动归营结束本趟，保留历史最高层数。
- **每日首通星尘晶**：每 10 层领取当日里程碑奖励，以 UTC+8 每天早 06:00 换日。同日同里程碑不重复领，更高难度只补差额。深渊不直接产金币，仍保留战斗经验、遗物与记忆奖励。
- **局内裂隙币**：用于本局商店和事件；结束时清空。购买是游戏内资源操作，没有真实支付。
- **永久记忆碎片**：战斗、部分事件和通关奖励立即保留；失败不清空。用于体魄、攻击、战后恢复和开局补给四条有上限的传承。四类传承全部升满后，可在营地手动按 1:1 将剩余记忆兑换星尘晶。
- **路径决策**：安全补给、未知事件与更危险遭遇产生不同收益；先解决节点再进入下一战。
- **五种随机事件**：赤红祭坛、迷失商队、回声之井、遗弃补给箱、古代锻炉，每种三个选项。界面明确列出资源代价、生命风险、概率或奖励。
- **局内商店与休整**：限量商品不能重复刷购；休整可在恢复/复苏、能量冷却和货币之间取舍。
- **祝福构筑**：保留角色专属祝福，增加通用的汲取生命、护盾进攻、击杀回能、残血处决、中毒、雷击等机制，低稀有度队伍也能形成组合。
- **难度挑战**：完成对应难度第 20 层后逐级解锁 1—3 阶挑战，本趟仍可继续向上探索；开局前选择，局中锁定；敌人强化与永久资源倍率明确展示，不按队伍强度暗中缩放。
- **固定敌人曲线**：生命、攻击、防御分别成长，限制速度；取消原来层数与指数倍率重复叠乘。更危险的遭遇有清晰词缀说明。

详细数值与实际模拟结果见 `validation/BALANCE_V2.md`（以最终验证文件为准）。

## 修复与合理性调整

- 初层不再随机出现高阶暗黑骑士；普通远征以逐步升级的遭遇池组织。
- 失败不能在原高层免费满血继续；进行中的远征锁定队伍，避免换人绕过生命继承。
- 遭遇与随机种子随存档保留，重复点击或重新打开不会重抽敌人和预定奖励。
- 节点、事件、商店和战斗结算都检查状态，不能重复领奖；保存失败会回滚资源变更。
- 主线按前置关卡依次开放；星级按胜利、队伍存活和通关回合取得，保留历史最佳。
- 取消单机远征的每日重置限制及付费重置：可免费结束并重新开始，代价是失去本局临时资源与祝福。
- 首领具备连续控制保护；自动战斗更合理地选用治疗与攻击。

## 保留原玩法

原有十名角色、两个章节十关、剧情、常驻/限定抽卡、保底与重复碎片、编队、等级/命座、遗物装备/强化/分解、金币商店、体力恢复和三槽存档继续可用。卡尔迪原立绘保留，其余九名角色接入生成的透明立绘。营地、冰霜雪原与深渊使用对应场景图；敌人沿用 Godot 版 SVG 绘图。

**模拟充值仍保留**，这是原项目“模拟氪金”的玩法，点击不会扣真钱。它不会直接发放远征专用裂隙币或记忆碎片。常规角色、等级和装备仍会影响远征实力，因此并不声称所有成长途径彼此隔绝。

限定五星的既有规则仍保留：非大保底时实际 UP 率 75%，大保底 100%；界面按实际算法说明。

## 存档与迁移

- 新版使用 **v4 存档**，支持导入原网页 v2/v3、Godot v1 的原始 JSON 和导出包装文件。
- **导入旧存档会保留角色、资源、装备、主线、历史最高层等永久进度，但旧版正在进行的深渊临时构筑会重置，从第一层开始新版远征。** 两套规则不同，不能直接延续旧局。
- 建议先在旧工程导出备份，再将其导入新版空槽；不要覆盖唯一备份。新版导出不保证能被旧版读取。
- 新版自身的进行中远征可以保存、重启恢复；事件与商店的消费状态随局保存。
- 测试使用隔离目录，不修改正常游玩存档。

请以 `validation/VERIFICATION.md` 的最终记录为准。单元测试中会构造结算数据来检查事务规则；**平衡结论只使用真正运行 BattleModel 的战斗模拟**，两者不混淆。自动测试通过不等于穷尽所有队伍、随机组合与设备。

当前测试平台为云端 Linux。没有运行 Android、Windows 或 macOS 真机验收，也没有完成听感验收。界面截图来自实际 Godot 运行窗口。

## 开发文件

- `scripts/game_model.gd`：存档、养成、主线、远征节点与资源事务。
- `data/rogue_v2.json`：事件、休整、传承配置。
- `scripts/battle_model.gd`、`scripts/abyss_balance.gd`：战斗与敌人数值。
- `scripts/main.gd`、`scripts/ui/`：原生界面、动画和交互。
- `tests/`：可重复运行的测试；`tools/`：测试和资源构建脚本。

每日任务、遗物套装和碎片商店仍不作为已完成内容。本轮主要完善远征与传承，不宣称原项目的每个占位功能都已补齐。

字体包括现有游戏文字和 GB2312 常用汉字，新增冷僻字可用 `tools/subset_font.py` 重建。原立绘/场景/文本沿用用户项目权利；新增 SVG 随工程提供，字体许可在 `assets/fonts/`。没有修改 GitHub、部署在线服务或启动独立 Codex/Work 任务。
