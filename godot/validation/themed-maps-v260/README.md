# 2.6 主题遗境

新出发将灰烬王城、苍翠秘林、星辉圣域各使用一次，保存独立随机排列。每幕保持同一环境，三个分区依次为外围、腹地、核心；幕序仍决定敌人成长和奖励档位。环境音乐随主题，首领及功能页面的既有音乐规则保留。

当前地图和已签发物品直接沿用存档。旧探索不补入环境排列，后续地图仍按旧分区生成，避免读档重抽。新环境顺序使用独立随机流，信使位置按三个分区各三分之一选区，再从该区合法节点选位；每幕一处，避开入口、固定初始补给与休息节点、宝库和钥匙房。位置随地图保存，首领寄送独立。

六个主题容器为物资容器的视觉扩展，搜索数量与品质公式保持。十二件主题战利品各对应一个既有基础条目：保留品质、尺寸、估价、类别、物品类型、效果和权重。变体不进入独立加权池；完成原抽选后才按环境替换名称、图标与ID，因此同一随机状态的品质、数量、占格、价值和后续随机状态一致。新增金红物品沿用藏品系统。

定向检查入口为 tests/test_themed_maps_v260.gd：六种固定种子，三幕主题/名称/场景深度，保存加载与旧探索，信使均匀分区的确定分支，以及物品变体经济等价。实际图像与移动布局由本版统一短时视觉验收记录，不运行全量或大型数值模拟。
