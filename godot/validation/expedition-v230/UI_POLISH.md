# 2.3 界面与操作验收

## 累计改进

本次保留2.2横屏双栏结构、原生更新与完整角色成长，在其上继续实现：自动搜索、稀有度节奏、格子原位揭示、精确目标格飞入与整理缓动、三态容器标记、满包直接使用/装备、购买前效果、护盾装备/背包专位、钥匙房、寄存、战前真实怪物与事件选择。减少动效只减少运动，不改变搜索用时与驻留。

角色页新增滚动位置记忆，重建列表后恢复选中位置；下方角色切换、属性页签切换、返回角色页与编队操作均有真实Viewport点击覆盖。编队选中卡与普通卡使用相同内边距，避免底部列表因卡片高度变化跳动。拥有/未获得使用独立勾选/锁定徽章，仅未拥有立绘降亮，不让说明文字一起变暗。

角色与祈愿使用环境背景、柔光和静态符文圆环，抽卡有独立单次/十连按钮、费用层级、保底与当前概率、揭示与全部结果、档案预览返回。十连结果保持5×2完整同屏。按钮按主操作、轻页签、圆形图标工具和卡片分型，搜打撤/深渊页签与角色筛选同步采用轻页签。

剧情恢复章节、锁定、关卡类型、已完成、体力与首通奖励图标，保留人物立绘和正文点击/继续/跳过操作。原网页的这些图标来自emoji语义，本版用统一SVG重绘，不声称原网页存在对应PNG。

商店保留原目录人民币标价¥6/30/68/128/328及原礼包内容，按钮为“购买”，模型仍直接发放奖励，不接支付SDK或外部收款，不扣除真实货币。金币兑换商品沿用原金币消耗。界面没有添加“免费模拟领取”等旁白。

## 实际发现并修复的缺陷

1. 桌面GL移动仿真误用显示器safe_area，挤窄搜索详情；现在只有真实mobile读取系统安全区。
2. 寄存动态规划复用候选字典，四枚物品坐标重叠；每个方案使用独立副本，并检查实际四纹理/六对矩形不相交。
3. 地图fit边界float误差允许额外24px拖动；无缩放边界加微小容差，1000组合修前89次、修后0次。
4. 搜索使用墙钟，后台恢复会跳过扫描；现在生命周期暂停冻结累计进度，恢复不瞬间揭示或收走。
5. 主按钮给彩色金币/宝石乘深色，变成实心黑图案；彩色资源保留原色。
6. 角色列表重建回到顶部、选中卡内边距不同导致底部轻微跳位；记忆位置并统一尺寸。
7. 装备盾详情曾沿用“剩余1回合”，现按装备来源显示实际剩余盾值，持久属性不伪装成一回合技能。

## 验证边界

Linux headless结果不替代实际GL图片。搜索/满包/寄存、地图、角色/剧情/祈愿/商店均做实际GL检查，并用真实Viewport输入检查交互。手机宽度覆盖1170×540、960×540及2340×1080物理窗口映射。

原生Android验证由CI执行，包含真实ADB点击、地图/背包/搜索、连续后台恢复和只读更新桥。新增搜索中后台验证仅在自然搜索中观察到安全长扫描窗口时执行；是否实际覆盖看search-background.json，不人为减慢游戏制造成功。实际S23+硬件手感与真实跨版本安装流程不冒充已测。

## 全页补齐的最终检查

补齐了遗物五槽独立透明原画、中文属性与图标、副属性滚动区、固定强化/装备操作、含角色立绘的装配弹层；强化收费、装配/取消、列表保位置和反馈不遮操作均通过真实输入。新增经验精粹图用于角色成长。

菜单按出发与养成分组，存档统计使用独立图标和值，成长属性/技能/命座与深渊工具/构筑逐项加入语义图。战斗状态入口改为圆形图标工具，详情攻击/防御改读实际unit.stats，而非不存在的平铺字段。祈愿规则的百分号格式错误经真实点击复现并修复，四项概率和保底文本检查通过。

最终完整聚合与生产快照一致；真实GL遗物96项、角色35项、祈愿110项，另逐页截图审阅。遗物提示改为不遮底部操作的小型上方反馈，不延长动画迁就测试。截图展示使用真实生成的20件遗物测试档案，不是玩家存档或设计稿。
