# 2.3.0 更新说明

版本：2.3.0 / 20300。沿现有正式自动更新渠道，固定签名与包名不变；原生 Android 与签名 CI 已全部通过；正式发布详见 RELEASE.md。

## 更新内容

- 新增32种物品、区域钥匙房、护盾装备与背包等级；搜索更丰富的战利品。
- 新增寄存手选/自动选择、安全多节点旅行与六类探索事件。
- 自动搜索保留稀有度节奏，格子原位揭示、精确飞入背包、整理缓动；满包可直接使用或装备。
- 改善地图适配与连接导航，搜索暂停/后台恢复不跳过进度。
- 全页界面统一图标与按钮层级；重制角色、祈愿、遗物、剧情、商店和深渊展示，修复角色列表位置跳动。
- 新增场景背景、遗物美术、许可音乐及短提示音；搜索不使用旧10秒音效。
- 完整保留玩家成长，以真实队伍与遗物校准跨玩法金币回报、盾装备收益和路线风险。
