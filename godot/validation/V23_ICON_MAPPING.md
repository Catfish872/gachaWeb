# v2.3 图标语义移植

原网页资源审计：`gachaWeb/index.html`、`js/data/abyssData.js`、`js/data/skills.js` 使用 Unicode/emoji 图标；并不存在对应的独立金币、宝石、祝福图标贴图。此版保留原图标的语义与种类，以自绘 SVG 统一表现，避免 Android 字体缺字或彩色 emoji 不一致。未声称这些 SVG 是原版图片。

- 钱包：🪙 → coin，💎 → gem，⚡ → energy。
- 回响：⚔️ → sword，❤️ → heart，🛡️/💠 → shield，🔋/⚡ → energy，🎯 → crit，🏕️ → camp，🌟/✦/✨ → star。
- 元素与技能：🔥/🌋 → fire，❄️/🧊 → ice，💚/🌿/🌳 → leaf，🐉 → dragon，💥 → burst，🌌 → void，💧/🌊 → water，💨/🌪️/☁️ → wind，🌩️ → energy，🦵 → kick。
- 传承与无 emoji 的节点，按 id 的明确含义选体魄/攻击/回复/物资等图标；未知条目使用星形，不再按 id 哈希随机绘制效果图。

按钮为自绘九宫格切角符文边框：保留原有44像素最小触控高度、8像素上下内边距；提供普通、悬停、按下、禁用四个状态，主操作金色、次操作蓝灰。图标不单独接收触摸。

资源：`assets/ui/runes/`；语义映射：`scripts/ui/rune_theme.gd`；回归：`tests/test_rune_theme.gd`。

## 剧情与章节
原 `StageUI.js` 以 🗺️、🔒、✓、⚡ 和普通/精英/BOSS徽章区分状态；新UI恢复为地图/锁/勾选、剑/王冠、体力、首通宝石图标。没有假称原版存在章节PNG图标。
原 `DialogueUI.js` 支持侧边跳过、元素色说话人、立绘、打字机与点击继续；现在保留并为说话人增加书卷/元素标识，跳过与继续为独立44像素触控目标，正文点按先揭示再推进。`test_story_presentation.gd` 在1170×540及960×540覆盖选关、逐句阅读、跳过、重复进入及控件可见范围。

## 追加：召唤与人物展示
- 审计原 `GachaUI.js`：原版区分单抽/十连的大字号数量、独立宝石价格、UP横幅与保底信息。新召唤恢复这些独立层级，不将全部操作拼成同种长文本按钮。
- 组件分型：`_tab_button` 为轻背景+选中下划；`_tool_button` 为44像素圆形图标工具；`_summon_cta` 为分层祈愿卡（金色十连，次级单抽）；结果预览保留独立返回。
- `_portrait_environment` 在透明角色立绘后添加已有元素场景、径向柔光与静态符文圆环；战斗仍用透明 `_portrait`，不把环境卡片带入战场。
- 十连5×2结果卡不滚动即可全部可见，星级为画面角标，不挤压第二行；点击角色打开只读档案，再返回全部结果。
- `test_summon_presentation.gd` 用真实 Viewport 点击覆盖1170×540和960×540下单抽/十连精确扣款、揭晓、跳过、预览不改收藏、结果返回、收下与全部卡片可见性。
