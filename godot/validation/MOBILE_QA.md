记录日期：2026-10-19。当前状态：修复后的最终 Android 验证待完成，实体手机验收待完成。

## 已取得的证据

Godot 4.6.3 的自动回归测试通过 317 项检查，覆盖 1080×2400、1080×1920、720×1600、2400×1080、1920×1080 五种屏幕尺寸。检查包含九个页面的布局、角色立绘比例、图片及角色卡上的滑动、点击与拖动区分、菜单导航、返回、弹窗旋转及战斗退出确认。这部分使用 Linux 上注入的触摸和指针事件。追加首页按钮完整边界、横屏单行资源栏及内容区域高度检查后，最新本地回归通过 417 项检查，日志干净。

实际 Android 测试运行于 API 35、x86_64 模拟器，采用软件图形渲染；竖屏为 720×1280，横屏为 1280×720。安装后的应用已完成导航、系统返回、拖动滚动、横竖屏切换和后台恢复操作。执行记录与截图见 [Android 验证运行](https://github.com/Catfish872/gachaWeb/actions/runs/39316659496)。

已逐张检查 20 张模拟器截图。所示页面的文字、返回与菜单按钮清晰，筛选项能够换行，角色养成及编队截图显示完整立绘，页面宽度适配正常。横屏内容通过纵向滚动查看。
