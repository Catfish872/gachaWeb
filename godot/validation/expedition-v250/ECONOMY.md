# 2.5.0 个人套装、定向遗物与经济复核

**3328条真实路线、126,970场战斗；执行与独立审计0错误。** 主经济矩阵3072条，独立难度效率对照256条；14项相关源码、数据和辅助文件在运行前后哈希一致。

## 主要结论

高难度确实提高了本组条件下的遗物获取效率。独立对照中，难度0～3的每局平均件数为 **10.000 / 13.922 / 17.922 / 22.047**，256局均完成50层。难度3相对难度0的每分钟件数为快速估时 **2.147倍**、从容估时 **2.182倍**；按32个seed成簇重采样的95%区间分别为2.063～2.226、2.097～2.263。这里是同seed严格配对属性：每个seed生成一份合法散件装备，四难度和首轮/同日重打共用，跨seed的合法属性roll可以不同，不能称为所有seed共用唯一同一库存。

全部样本实际取得 **41,528件**新遗物，**41,528件命中目标套装**，六套均有覆盖；其中四星26,280件、五星15,248件。所有本局新增未强化物均通过真实接口批量出售，合计现金10,472,640金币，深渊直接金币仍为0。件数是“曾取得”，不是出售后仍持有；不能把现金与保留装备的成长收益重复计算。

主矩阵中，完整50层的全部新遗物实际售出金为同队搜打撤三幕完整净金币的 **11.1%～15.4%**；仅新普通层额外部分为0%～5.6%。按全部出发的实际总收入/总估时，深渊遗物金币率为对应搜打撤净金币率的 **14.0%～33.7%**。本组条件下，搜打撤仍明显是主要金币来源。难度3完整50层理论卖出期望为5304金币（原里程碑3000，加新额外期望2304）；独立效率组实测均值5424，有限样本存在波动，未据此再调价。

合法个人四件套改善了高风险生存，而非凭空提高战利品定价。限定毕业队风险5在保药和默认两种策略下，均从散件 **21/64** 通关提高到主题套装 **27/64**；全出发净收益分别增加 **2396金币**（配对95%区间714～4526）、**2215金币**（753～3941）。只看双方都通关的配对种子，金币差为−47/+232，说明本批主要收益改善来自多存活的6局。风险4为63/64→64/64，收益差区间跨0，不作普遍收益承诺。

每日首次通关奖励每10层按难度为 **900 / 1350 / 1800 / 2200钻**，完整50层共4500 / 6750 / 9000 / 11000钻。**单独每日奖励**相对同队三幕完整净金币×0.1为 **2.303～2.703倍**，16个配对组的均值均落在约2～3倍目标内。满营地另加本局新增记忆兑换为 **2.479～2.898倍**，单列观察。仅日奖的95%区间有15组完整落在2～3内；输出毕业风险5默认组只有9次成功，其区间为2.347～3.049，均值2.671，应连同成功样本量阅读。全部出发收益与失败保留资产另列。

## 样本与方法

本版在日奖配置确定后完整重跑3328条路线。与相同种子的调奖前记录逐字段对照，2159条完全相同，1169条仅每日奖励、每日奖励明细与钻石合计变化；所有夹具和其余已记录战斗、掉落、唯一物品编号、成长、补给及金币字段相同。

主样本种子35500000～35500063。保留初始、成长、限定毕业风险4/5、输出毕业风险5、十二选散件毕业风险5六个基线组；新增限定毕业主题四件套风险4/5，共八组。每组两种搜打撤补给策略各64局，深渊共用空/满营地、首轮/同日重复四组观察。独立效率对照使用35600000～35600031，不并入主搜打撤收益比；采用相同限定毕业队、无套装构建规则，四难度各首轮和同日重打，仅满营地。

散件显式调用真实generate_relic的空setId参数，避免新默认随机套装污染对照。主题组通过真实生成、强化25级和装备接口，为卡尔迪、艾拉、格斯分别配置4件炽焰、极光、雷霆套装，项链为散件；64个theme/legacy同seed夹具逐件属性、强化roll和造装后RNG完全一致。这是机制主题搭配，不是全库存最优，也未逐局运行库存优化器。初始与成长组不补装备。角色命座和遗物视为既有养成条件，不将测试造装资金算作通关收入。

常驻套装值按目录与原属性、等级暴伤公式独立复算，确认只加入一次。每战核对模型冻结快照与Battle中对应角色的ownerEffects，共734,968次边界检查；签发快照的整数/浮点JSON类型差按数值语义处理，不改变实际效果。六种深渊目标按seed轮换，每次准备锁定完整奖励；计划与结算UID、套装、品质、主副属性和实际出售现金逐项核验。

每5层四星、每10层五星保底保留，普通层额外概率为0/10/20/30%，额外品质四星80%/五星20%；50层理论件数10/14/18/22。为了可比，只在局外一次性全卖本局新增未强化物，旧装备不动、不用新物换装；不包含逐件筛装耗时。每分钟值采用声明的战斗步数、选择、移动、搜索和实际操作耗时假设，并非CPU运行时间或实测手机游玩速度。

保药策略用真实锁API各保留一件治疗、修理、能量、复苏，手选寄送时排除保留物；默认策略不加锁并直接自动寄送。红盾与背包19000金币前置资本、三把钥匙1500金币周转资本单列。寄送只转移实物，收入必须实际局外领取出售；未用采购钥匙按资本保留的经营口径与实际清算口径分列。

每日领取按各10层里程碑已领金额补差；同日重打已足额里程碑为0，提高难度只补差额。旧已领记录保留，同档旧金额在再次完成相应里程碑时补225 / 350 / 450 / 575钻，读档保留原余额；跨日重置当日领取记录。

旧规则继续实际执行：钥匙500、首领6×6/寄存站5×5寄送、每处一次且费50、服务驻守15%、同幕固定tier最多6%成长、末幕仅首领本体四维15%、感电35%、完整异常、无限祝福与总减伤90%。本批首幕首领寄后平均占19.4～21.2/60格，每局寄2.86～4.09次；失败组已寄且真实卖出资产均值12,431～23,471金币。完整钥匙房回本、驻守、补给、背包压力与感电实际机会统计均在报告中保留。
