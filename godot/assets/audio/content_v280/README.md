# 风路同行 · 新章节音频

本音频包使用本次编写的乐谱与程序合成音色，制作脚本为 `godot/tools/audio/build_windpass_audio.py`。旋律、伴奏、低音、打击乐与音效均由脚本定义，素材输入仅为数值参数；现有歌曲、录音、音色采样库与声库均未进入制作链。曲目沿用项目轻量幻想配乐的混音尺度，并采用键盘式拨弦、柔弦和框鼓。制作归属本项目，现有素材的授权声明保持独立。

五首曲目分别有完整八小节旋律与和声，再以呈示、回答、变奏、回归形成三十二小节结构。风谷以柔和键盘式主旋律和拨弦伴奏为主，风廊保留槌音主声并采用键盘式应答，首领曲保留低鼓与分拍，缇雅主题采用轻快的上行旋律，露弥主题采用较长乐句与低音区回答。配器属于合成幻想音乐，并非真人演奏或交响乐录音。

所有资源为 44.1 kHz 双声道 Ogg Vorbis。五首背景音乐统一为约 −22 LUFS，解码后真峰值低于 −9 dBTP，给战斗反馈预留空间。循环从第一个采样点持续至音频结尾，音符余音及空间反射环绕写入起点。这里的循环检测仅确认信号接缝，旋律衔接与长期聆听体验仍需实际试听。

## 音效与事件

角色音效为 `tiya_basic`、`tiya_skill`、`tiya_ultimate`、`lumi_basic`、`lumi_skill`、`lumi_ultimate`。缇雅使用迅速掠过的风刃与上行音，露弥使用柔和气流与分解和音。常规反馈持续约 0.24–0.48 秒，两人大招分别为 1.15 与 1.25 秒。

环境与敌人音效为 `wind_pierce`、`wind_field_open`、`wind_field_pulse`、`wind_field_release`、`roc_warning`、`roc_gust`、`wind_mechanism_turn`、`windpass_reveal`。首领预警持续 0.65 秒，章节揭示为 1.1 秒，其余为 0.18–0.46 秒。贯穿与风场脉冲使用低音量且单次行动只选一声，大招覆盖同一事件组内的普通技能与追加贯穿。音效自身峰值约 −8 dBFS，贯穿和脉冲约 −10 dBFS；运行时仍叠加项目效果音量，建议相对总音量分别为 −9 dB 与 −15 dB。

`godot/scripts/windpass_audio.gd` 只负责选音，调用者负责播放、静音、暂停恢复、节流与最多两声的通道管理。`music_path(track)` 返回五首曲目的路径，其余返回空字符串以沿用旧路由。`battle_sound(events, units)` 读取真实技能与伤害事件，风场释放通过既有死亡事件与单位标识解析。`field_entry(data_id)` 是显式场景进入接口；现有战斗模型没有单独的风场开放阶段事件，因此接入者应在实际入场点调用一次。

播放背景音乐时继续使用原曲池、交叉渐变与游标恢复。背包、详情页、奖励和补给页沿用当前曲目，进入风主题或限定池时才更换主题。抽卡长曲与 `windpass_reveal` 短提示音分别属于音乐与效果通道，音量及静音设置应独立生效。

## 检测与试听状态

`manifest.json` 记录资源路径、曲目结构、时长、来源、大小与 SHA256。`verification.json` 记录实际解码结果、响度、真峰值、循环接缝及单声道混音损失。检查确认全部文件和项目旧音频的字节摘要不同；原创来源由可检查的作曲与合成脚本共同说明，摘要差异本身不构成原创性证明。

音频输入工具在本次环境返回不支持音频输入，故主观试听标记保持待完成。当前结果为可接入、通过信号检测的原创合成音频；真实播放中的音色自然度、旋律表现、重复疲劳、声音辨识度与战斗混音仍需试听，尚未声称通过手游听感验收。

可用 `python godot/tools/audio/verify_windpass_audio.py --preview-dir <本地目录>` 生成五曲各十二秒的拼接试听、逐曲片段、首尾各三秒的循环接缝试听与音效合集。完整歌曲见本目录。制作脚本依赖 Python、NumPy、SciPy 与 FFmpeg，随机合成种子固定；音频编码器生成的容器标识可变化，资源摘要对应当前实际交付文件。

## 2026-11-03 主声音色调整

根据实际试听反馈，本次保留五首曲目的全部旋律音符、八度变化、起音时点、时值、节奏、和声和曲长，以及原有键盘式拨弦伴奏。风谷、首领、缇雅、露弥四曲的笛声或簧管主声改为柔和键盘式音色；风廊保留槌音主旋律，只替换笛声应答。新主声采用与既有伴奏同类的击弦合成模型，将起音由约 3 毫秒柔化到 12 毫秒，并衰减高次泛音。声部增益由 0.235 调整为 0.185，约降低 2.08 dB；整体继续归一到约 −22 LUFS。

十四个战斗与环境音效保持逐字节一致，游戏选音、音量控制与播放逻辑保持原状。`--music-only` 可单独生成音乐并保留既有音效。记录中的信号检测说明音频可解码、循环与峰值符合预算，实际听感仍由后续试听确认。
