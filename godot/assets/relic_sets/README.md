# 遗物套装美术 · 2.5.0

本目录保存六套遗物、每套五个部位的独立美术。部位顺序为头盔、胸甲、腰带、靴子、项链；套装顺序为炽焰誓约、极光祷歌、雷霆追猎、疾风星途、城垣誓卫、星辉守望。

`relic_sets_atlas_v250.png` 由内置 `image_gen.imagegen` 一次生成，尺寸 1145 × 1374，RGBA 格式，2,865,182 字节。生成请求启用真实透明背景，原始像素完整保留；633,767 个像素的透明度为零。源文件 SHA-256 为 `39bca1ce57af733b9651aeff390691f698e5a3f99298b859b7f8497f5b48585b`。完整生成提示词见 `generation_prompt.txt`，机器可读来源、矩形坐标、虚拟边距见 `art_manifest.json`。

游戏通过 `res://assets/relic_sets/{set_id}/{slot_id}.tres` 读取美术。每个 Godot AtlasTexture 使用按实际图像单独拟合的整数矩形、虚拟透明边距和 `filter_clip = true`；源 PNG 保持原样。虚拟边距将各个部位统一为带留白的正方形，供 TextureRect 按比例居中显示。原有通用部位图标继续由界面作为资源缺失时的回退。

原图的行列间距较紧。城垣誓卫靴子的左侧裁取坐标为 x=692，用于隔开旁边的腰带，仅舍去透明度为 17、23、22（满值 255）的三个外缘像素；所有实色轮廓保留。其余矩形覆盖对应物件的全部主要连通区域，各个裁取区域均已检查邻件串入。

`tests/test_relic_set_art_v250.gd` 检查三十份资源、目录映射、唯一矩形、边距、透明度、完整原图哈希，共 365 项。`tests/capture_relic_set_art_v250.gd` 使用 Godot Image 接口输出 40、80、160 像素的接触表，便于核对生产资源的裁取位置；`tests/capture_relic_set_art_gpu_v250.gd` 在授权图形会话中通过实际 TextureRect 截取对应 GPU 渲染结果。验证图输出到 `validation/relic-art-v250/`，与生产素材分开。

40、80、160 像素接触表已逐张检查。六套的轮廓、配色和材料具有区分度。40 像素下项链链条和金属细纹的细节减少，吊坠与套装的主要形状仍可辨认。较大的角色装备格建议沿用 64—80 像素显示尺寸。
